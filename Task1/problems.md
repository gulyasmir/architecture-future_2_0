# **Проблемные места сейчас**


| Проблемная область                                            | В чём проблема                                                                                                                                                                                           | Чем мешает бизнесу                                                                                                                                                                                                      |
| ------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **DWH на старом SQL Server 2008**                                      | Устаревшая платформа, плохо масштабируется, нет поддержки современных инструментов обработки данных и интеграций. | Медленные отчёты, высокие затраты на поддержку, риск инцидентов, ограничение роста бизнеса.                                                                |
| **Большая бизнес-логика в DWH**                            | Вся логика «зашита» прямо в БД: stored procedures, триггеры и т.д.                                                                                                               | Любые изменения требуют много времени и специалистов SQL, увеличивается time-to-market для новых сервисов.                                                   |
| **Power Builder интерфейс**                                           | Устаревший клиент для операторов, сложно развивать и интегрировать с новыми системами.                                                     | Усложняет обучение новых сотрудников, мешает автоматизации бизнес-процессов.                                                                                         |
| **Старая интеграционная шина (Apache Camel)**          | Старая реализация, слабая поддержка масштабируемых микросервисных коммуникаций.                                                               | Замедляет подключение новых бизнесов (например, фармацевтики и производителей оборудования).                                                            |
| **Данные медицинские и финансовые смешаны** | Медицинские данные и финансовые данные хранятся в одной системе.                                                                                              | Растёт риск ошибок, повышается стоимость разработки, сложнее соответствовать требованиям законодательства по защите данных. |
| **Медленная генерация отчётов в BI-системе**  | Из-за объема и сложности трансформаций отчеты формируются часами.                                                                                            | Бизнес не может быстро принимать решения, теряет конкурентное преимущество.                                                                                            |
| **Отсутствие чётких доменных границ**            | Все данные централизованы, без выделения по бизнес-направлениям (медицина, финансы, ИИ).                                                     | Трудно развивать каждое направление независимо, блокируются инициативы по быстрому запуску новых продуктов.                               |
| **Трудности интеграции новых бизнесов**        | Для каждой новой компании нужно «вшивать» интеграцию в DWH через код.                                                                                         | Долгое подключение партнёров и новых компаний, потеря возможностей роста.                                                                                                |
