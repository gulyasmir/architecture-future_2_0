# Технический радар для "Будущее 2.0"

Зоны радара



| Зона   | Что означает                                                                                         |
| ---------- | --------------------------------------------------------------------------------------------------------------- |
| **Adopt**  | Уже используется стабильно (основной продакшн-стек)                 |
| **Trial**  | Тестируем / внедряем в отдельных проектах                                    |
| **Assess** | Изучаем, рассматриваем к внедрению                                                |
| **Hold**   | Старые или нежелательные технологии, которые нужно выводить |

### Представлю радар в виде таблицы



| Категория     | Технология / Методология   | Статус | Комментарий                                                                                |
| ---------------------- | ----------------------------------------------- | ------------ | ----------------------------------------------------------------------------------------------------- |
| Backend                | Node.js + NestJS                                | Adopt        | Основной стек для микросервисов                                           |
